# ASR Service (语音识别任务服务)

**源码位置**: `services/asr/`
**框架**: `FastAPI`, `FunASR` (阿里底层开源库)
**基础镜像环境**: 高版本 Python + 编译版 PyTorch 环境

## 核心架构功能
这是一个功能及其单一且纯粹的基础硬件能力转化容器。它接收一堆毫无意义的字节或者波形（来自真实录制或者 Web 端收集），利用离线深度网络推导出中文字符串返回。

## 关键架构决策与选型

### 极度沉重的容器体积隔离
这个微服务单独抽取后，它包含体积超 5GB~7GB 的重量级深度学习轮子（如果带有 CUDA 则更加庞大）。把它变成一个独立的 Docker 服务之后，只要这个镜像在系统的底层文件缓存层 (OverlayFS) 构建完成，它在物理硬盘上的结构就锁死了。后续我们频繁去跑 Gateway 或者 RAG 或大模型调试的小 Python 代码变动重构时，不再需要拉取构建安装漫长的 PyTorch 下载过程，做到了敏捷开发。

### SenseVoiceSmall 高敏感度模型
1. 它的参数体量较普通模型更小计算速度极快。对于小孩子随时随处脱口而出的一个短词，旧版的 Whisper 可能会等很久或者直接吞音，它的长短语音区分模型非常好。
2. 相比旧版的大部分离线 ASR 模型，**自动加入标点符号**成为了极强的附加项优势。对于大语言模型判断儿童这到底是疑问句还是感叹句有决定性价值。
