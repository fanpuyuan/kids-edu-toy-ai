# TTS Service (文本发音变调服务)

**源码位置**: `services/tts/`
**框架**: `FastAPI`, `edge-tts`
**网络角色**: 将 LLM 生成的长字符串流转为高情感拟真音频流的搬运组。由于采用了免费的微软线上云接口，本容器镜像体积极轻。

## 核心架构功能
玩具能否让人感到是一个“玩伴”，重点取决于声音流露出的感情以及互动速度。
入口只专注于处理将文字转换 `POST /tts` 。

## 关键微服务设计选型
- **彻底瘦身摆脱本地显存占用**：目前由于本机显卡绝大部分资源已经被大语言模型（Ollama/Qwen 等等参数量在几十亿级别的进程）或者处理复杂图片的服务吃干净了。如果本地再跑一个包含复杂 Diffusion 或端到端音位生成的 TTS 的话会直接资源瓶颈 OOM。
- 通过爬虫伪装请求的手段，利用 `edge-tts` 包将长长的一段回答无缝从微软云端的生成接口里抠取 MP3 音轨并直接返回，不再依赖本地资源去进行耗时的波形合成。
- **配置透传化能力**：由于该服务属于单纯下游执行终端，它在被上游（网关）调用的瞬间，直接将前端调配好的定制角色音色标识带入请求（如：`zh-CN-YunxiNeural` 阳光运动系小男生口吻，或者带入参数拉高原本的语速以适应紧张讲故事的快节奏环节）。
