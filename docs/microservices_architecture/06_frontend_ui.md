# Frontend UI (Web家长操控台与交互端)

**源码位置**: `services/frontend/`
**框架**: `Streamlit`
**网络角色**: 可视化一切底层执行，并用以代替目前正在开发空缺阶段的“树莓派/实体儿童玩具主板”功能的唯一触控终端。所有的接口交互全都遵循并指向唯一的 `/gateway` (网关层)。

## 页面划分布局架构与能力支撑

为了支持无痛的 RAG 知识输入与家长监控，当前分为四套核心面板：

### 1. 🎤 语音助手面板 (Voice Terminal Emulation)
- 该面板旨在完全复刻出一个“拿着玩具对话”的过程。
- 利用前端自带 `audiorecorder` Web 组件流式录制用户的口述音频，拿到 Blob 波形包通过 WebSocket 发包到后台，等待回调。回调回来后直接挂载浏览器的 HTML5 原生 `<audio>` 标签自动进行扩音播放。 

### 2. ⌨️ 文字聊天面板 (Debug Text Console)
- 在开发模式下，或者是不方便发出声音排查的时候，这就是经典的 ChatGPT 原生体验页面。通过 WebSocket 渲染纯字符形式的长串流，并且通过 Markdown 进行前端颜色区分输出，排查 Brain 到底哪一秒响应缓慢。

### 3. 📚 专属知识库面板 (RAG Database Management)
- 向普通家长等非开发人员提供简单的知识录入通道。用户只需要拖拽一份写有床前故事、幼儿百科的文档 (`.txt`, `.pdf`, `.md`, `.docx`) 扔向该模块。
- 即刻触发后台 RAG 的复杂 Ingestion 清洗切割管道（底层完成自动调用 BGE 与 BM25）。并由 UI 给用户反馈一个成功切割成了上百篇碎片文档的弹窗交互感。

### 4. 👨‍👩‍👧 记忆档案面板 (Parent Control Configuration)
- 给于家长直观的配置重写权：玩具对儿童的限制与背景记忆。
- 提供简单的文本框区域和预置的 `SYSTEM` 与 `FAMILY` 选择下拉列表。
- 文本框与内网后端的系统文件级储存 (`Markdown` 持久化模块) 执行实时状态一致性拉取，所写即所得。这免除了过去经常需要通过进入宿主机 Shell 层面改配置文件从而实现改人物设定的巨大弊端。
